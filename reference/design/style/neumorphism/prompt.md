## Neumorphism

- **Category:** Design Style
- **Style ID:** `neumorphism`
- **Cue:** Soft extruded surfaces, paired light and dark shadows, one-tone base

### Instructions
- Shape the interface as soft extruded and inset surfaces carved from one continuous base tone, using paired light and dark shadows for depth, rounded corners, and minimal crisp icons and text. Follow the Color instructions when given.
- When no Color, Lighting, or Texture instructions are given, use a light cool gray base with one subtle accent, soft diffuse light from the top left, and a smooth matte surface.
