## Minimalism

- **Category:** Design Style
- **Style ID:** `minimalist`

### Instructions
- Reduce the design to a few purposeful elements with generous negative space, precise spacing, and a clear focal hierarchy. Use restrained shapes and deliberate contrast. Every visible element must serve the subject. Follow the Color instructions when given, without decorative clutter.
- When no Color, Lighting, or Texture instructions are given, use a near-white base with one accent hue, soft even light, and a smooth clean surface.
