## Logo

- **Category:** Design Format
- **Style ID:** `logo`
- **Cue:** Single scalable mark, clean negative space, recognizable as a tiny silhouette

### Instructions
- Create a distinctive, scalable logo or symbol with a clear silhouette and balanced proportions. Keep small-size recognition and clean negative space. Integrate any rendered text as a legible wordmark. Avoid imitating existing trademarks. Present the flat logo itself on a plain background, with only the requested text.
