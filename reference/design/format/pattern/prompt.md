## Pattern

- **Category:** Design Format
- **Style ID:** `pattern`

### Instructions
- Create a seamless repeating surface pattern with a balanced motif distribution, consistent scale, and no visible seams at the edges. Keep spacing rhythmic and the overall texture even across the canvas. Spread the motifs evenly from edge to edge as an all-over repeat; if text is rendered, repeat it as part of the motif. Output the flat pattern itself as the full image.
