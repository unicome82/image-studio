## App Screen

- **Category:** Design Format
- **Style ID:** `appscreen`

### Instructions
- Design a single flat mobile app screen with a clear top bar, focused primary content, and consistent components on a tidy grid. Keep touch targets, spacing, and hierarchy coherent for one task. Use only supplied wording when typography is enabled; otherwise use unlettered placeholder blocks. Output the screen itself, without a phone frame, hand, or device mockup.
