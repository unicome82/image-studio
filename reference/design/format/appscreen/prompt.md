## App Screen

- **Category:** Design Format
- **Style ID:** `appscreen`

### Instructions
- Design a single flat mobile app screen with a clear top bar, focused primary content, and consistent components on a tidy grid. Keep touch targets, spacing, and hierarchy coherent for one task. When no text is rendered, use unlettered placeholder bars for interface copy. Output the screen itself, without a phone frame, hand, or device mockup.
