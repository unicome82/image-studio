## Long Exposure

- **Category:** Photo Technique
- **Style ID:** `longexposure`
- **Cue:** Long exposure, silky light trails and water, sharp static elements

### Apply
- Use a tripod long exposure so moving light, water, clouds, or people blur into smooth trails while static elements stay sharp.
- Keep the chosen Photo Style, Color, and Tone; this technique only changes how the frame is captured.
