## Childlike Illustration

- **Category:** Base Style
- **Style ID:** `childlikeillustration`

### Style
- Convey the imaginative visual logic of a young child without imitating a specific existing artwork.

### Shape
- Use straightforward symbolic representations, disproportionate parts, naive object relationships, and delightfully literal visual inventions.

### Avoid
- Avoid adult-perfect anatomy, professional mascot conventions, and calculated sophistication that contradicts childlike invention.
