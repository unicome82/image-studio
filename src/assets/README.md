# Material Symbols

Locally bundled Google Material Symbols Outlined SVGs, from [google/material-design-icons](https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7), commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`. Apache License 2.0; see `material-symbols.LICENSE.txt`.

Only the 12 symbols used by this interface are included. `Icon.tsx` references this local sprite. No icon font, Google Fonts stylesheet, CDN request, or runtime dependency is used. Symbols retain their original viewBox; auto_awesome uses its original implicit 24×24 coordinate space.
